## What it does

`main.ts` writes a single sentence of at most 200 characters to
`/output/entry.txt`. The sentence explains the modern internet to a
time traveler who has just stepped out of the year 1800, using only
things a person from that year already knows: a library, a post
office, a market stall, and a road. One picture, no list of features,
no word coined after the traveler's time.

> Picture every library, post office, and market stall in the world
> joined by one road, so any letter, book, or song reaches any door
> in a blink.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22 or later. No dependencies, no network access.
